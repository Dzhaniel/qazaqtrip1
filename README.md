# QazaqTrip — Қазақстанды ашыңыз

**Туристический гид на казахском языке для иностранных туристов.**
Проект регионального конкурса «IT-продукты, использующие казахский язык».

MVP полностью покрывает один город — **Кызылорду** (данные: `src/data/cities/kyzylorda.json` —
единственный источник правды). Остальные города (Астана, Алматы, Түркістан, Шымкент, Ақтау)
— карточки **«Жақында»** (coming soon).

---

## Возможности

- **Казахский — язык № 1** всего интерфейса (кириллица: ә ғ қ ң ө ұ ү һ і), переключатель **KZ / EN / RU**.
  Контент (названия, описания, фразы) — из полей `{kk,en,ru}` JSON-файла города.
- **Дизайн** — светлая photo-driven тема в стиле Visit Dubai / Visit Japan:
  тёплый белый фон `#FFFDF8`, turquoise `#1BA3B8` — главный акцент, золото `#E0A526`
  только для мелких акцентов и кнопок, текст — `#0F2A3D`. Большие скруглённые карточки (24px),
  плавный zoom фото при наведении. Ою «қошқар мүйіз» — только как тонкие разделители и очень
  лёгкий паттерн (4%) в ОДНОМ месте — футере.
- **Главная**:
  - полноэкранное фото Кызылорды (`/images/hero.jpg`, gradient-фолбэк) с лёгким градиентом
    для читаемости, заголовок, короткий теглайн, одна primary и одна secondary кнопка;
  - **floating-планер** (белая карточка поверх нижнего края hero): город, даты, чипы
    интересов, «Маршрут құру» — предзаполняет форму ЖИ-гида (`location.state`);
  - «Қалалар» — большие фото-карточки: Кызылорда активна («Қазір»), остальные — grayscale + «Жақында»;
  - «Міндетті түрде көріңіз» — горизонтальная лента из 5 карточек с большими фото
    (поле `image` из JSON → локальный реестр `src/lib/images.ts` → градиент);
  - «Қазақша үйреніп көріңіз» — 3 фразы с 🔊;
  - «ЖИ-гид қалай жұмыс істейді» — 3 шага.
- **Город `/city/kyzylorda`**: фото-шапка с именем города + sticky-таб-бар;
  разделы на отдельных страницах: sights / hotels / map / phrases.
  - достопримечательности: фильтры по категории и интересам, адрес, часы, билет, время,
    «Картадан көрсету» и «Бағдар алу» (Google Maps из `map_query`);
    `type: "day_trip"` — бейдж **«Қаладан тыс»** + `travel_note`, вынесены в отдельный список
    (карта не растягивается на 170 км);
  - отели: фильтр по цене, сортировка, рейтинг, бейдж завтрака, `price_note` по раскрытию;
  - **карта Leaflet + OpenStreetMap (без API-ключа)**: теal-пины мест, gold-пины отелей,
    попапы с ценой/билетом и ссылкой на маршрут, список синхронизирован с картой;
  - фразы: транслит + перевод + 🔊.
- **ЖИ-гид** (отдельная страница `/guide` + плавающая кнопка на всех страницах):
  - форма: даты, путешественники, бюджет (үнемді / орташа / жоғары), чипы интересов из
    `interest_options`, язык ответа;
  - свободный чат («Мен қазанның 17-20 аралығында Қызылордада боламын…»);
  - запрос уходит в **`/api/guide`** — серверную функцию, которая кладёт **весь
    `kyzylorda.json` в system prompt** модели;
  - **демо-режим без API-ключа**: маршрут строится локально из JSON (интересы, `visit_min`,
    часы работы, бюджет) — приложение работает даже при `vite dev` без сервера;
  - стриминг (SSE на Vercel) + typing-анимация, состояния загрузки/ошибки, быстрые подсказки;
  - UI маршрута: таймлайн по дням, таблица бюджета (гостиница — от `price_from_kzt`, билеты
    только там, где есть цена, неизвестное — «нақтыланбаған»), список неизвестных цен.
- **О правилах данных** (обязательно соблюдены):
  - `null` → **«Баға нақтыланбаған»** / «Уақыты нақтыланбаған» — никогда 0 и не догадки;
  - `coords_approx: true` → на пине пунктирная обводка + «шамамен / approx.» в попапе;
  - «Бағдар алу» всегда `https://www.google.com/maps/search/?api=1&query=<map_query>`;
  - `verified: false` → бейдж **«деректі тексеріңіз»**, а `meta.disclaimer` — в футере каждой страницы;
  - **Байқоңыр** (`restricted: true`): жёлтая (amber) карта-предупреждение с текстом пропуска —
    **перед** любыми деталями; в маршрут гид его добавляет только вместе с этим предупреждением;
  - цены Байконура показаны в **RUB без конвертации**.

## Стек

React 18 · Vite 5 · TypeScript · Tailwind CSS · react-router 6 · react-i18next (kk/en/ru) ·
Leaflet + OpenStreetMap · lucide-react · Serverless-функция `/api/guide`
(Vercel **и** Netlify, общий ядро в `server/guide-core.ts`) · OpenAI `gpt-4o-mini`
(опционально) · Vitest + jsdom.

Шрифты с полной поддержкой казахского: **Manrope** (UI) + **Playfair Display** (заголовки).

Фото: `public/images/` (Wikimedia Commons, Creative Commons — атрибуция в
`public/images/CREDITS.md`). Приоритет: поле `image` в JSON города → реестр
`src/lib/images.ts` → градиент-фолбэк по категории. Перезагрузка фото:
`node scripts/fetch-images.mjs`. Данные города — без изменений: `image` — опциональное
поле, в `kyzylorda.json` его нет (реестр живёт в коде).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

> Без серверной функции гид автоматически работает в **демо-режиме**
> (маршрут строится локально из `kyzylorda.json`) — приложение полностью функционально.

### Проверки

```bash
npm run typecheck   # tsc --noEmit
npm test            # vitest + jsdom: рендер всех страниц, правила null/verified/Baikonur
npm run smoke       # сценарии демо-планировщика (ассерты на данные)
node scripts/check-i18n.mjs   # все i18n-ключи присутствуют в kk/en/ru
npm run build       # production-сборка в dist/
```

## Переменные окружения (только сервер!)

| Переменная       | Обязательно | Описание                                             |
| ---------------- | ----------- | ---------------------------------------------------- |
| `OPENAI_API_KEY` | нет         | Ключ OpenAI для `/api/guide`. **Живёт только на сервере**, в браузер не попадает. Без него — демо-режим. |
| `GUIDE_MODEL`    | нет         | Модель (по умолчанию `gpt-4o-mini`).                  |

Локально (опционально, для настоящего AI-режима):

```bash
# Vercel: запустит dev-сервер + serverless-функции
npx vercel dev
```

## Деплой

### Vercel (основной)

1. Загрузите репозиторий в Vercel (framework: **Vite**, команда сборки по умолчанию).
2. В Settings → Environment Variables добавьте `OPENAI_API_KEY` (и опционально `GUIDE_MODEL`).
3. Deploy. Функция `api/guide.ts` автоматически доступна как `/api/guide` (SSE-стриминг).

### Netlify

1. Репозиторий → Netlify (build: `npm run build`, publish: `dist`).
2. Functions уже настроены в `netlify.toml` (`netlify/functions/guide.ts` → `/api/guide`,
   без стриминга — полный JSON; UI-анимация стриминга при этом сохраняется).
3. Добавьте `OPENAI_API_KEY` в Site settings → Environment variables.

Оба варианта дают публичный URL; SPA-fallback настроен (`netlify.toml` / Vercel по умолчанию).

## Как добавить город

1. Положите JSON с той же структурой: `src/data/cities/<id>.json`.
2. Добавьте одну строку в `src/data/cities/index.ts`:
   ```ts
   import almaty from './almaty.json';
   export const cities = { kyzylorda, almaty: almaty as unknown as CityData };
   ```
3. Готово: маршрут `/city/almaty` заработает, а на главной карточка города станет активной
   (уберите город из `comingSoonCities`).

## Примечания

- `visit_min` и `interests` — редакционная оценка (см. `meta.data_rules`), не официальные данные.
- Все цены/часы — из открытых источников (`meta.sources`), дата последней проверки: `meta.last_checked`.
  Поэтому в футере каждой страницы — дисклеймер из `meta.disclaimer`.
- Демо-режим и AI-режим возвращают одну и ту же структуру (`days/budget/notes/unknownPrices/phrases`),
  поэтому UI не различает их, кроме бейджа «Демо режим».
